# Guide — gérer ton portfolio

Ce guide explique comment ajouter et modifier le contenu de ton site **sans toucher au code**.
Tout se passe dans l'espace d'administration, depuis ton navigateur.

> 💡 Rien n'est jamais perdu : chaque modification est enregistrée avec un historique.
> En cas de doute, demande avant de supprimer quelque chose.

---

## 1. Se connecter

1. Ouvre l'adresse de ton site suivie de **/admin**
   (par exemple `https://eva-masson.netlify.app/admin`).
2. Clique sur **« Se connecter avec GitHub »**.
3. Saisis ton identifiant et ton mot de passe GitHub (la première fois, GitHub te demande
   d'**autoriser** l'application : clique sur le bouton vert).
4. Tu arrives sur le tableau de bord : à gauche, la liste des **collections**
   (Projets, Catégories, Rôles, Expérience professionnelle, Réglages du site).

---

## 2. Ajouter un court-métrage (avec images et lien vidéo)

1. Dans la colonne de gauche, clique sur **Projets**, puis sur le bouton **« + Projet »**.
2. Remplis le formulaire. À droite, l'**aperçu** te montre le résultat en direct.

| Champ | Ce qu'il faut mettre |
|---|---|
| **Titre** *(obligatoire)* | Le titre du film, ex. *Tempo* |
| Crédit | Facultatif : le nom du réalisateur, ex. *Eva Masson* |
| **Catégorie** *(obligatoire)* | Choisis **Courts-métrages** dans la liste |
| Type | **Scolaire**, **Professionnel** ou **Personnel** |
| Date | Facultatif : seule l'année est affichée |
| Rôle(s) d'Eva | Clique dans le champ et choisis un ou plusieurs rôles (Réalisatrice, Scénariste…) |
| Description courte | Une ou deux phrases : elles apparaissent quand le lien est partagé sur les réseaux |
| Description longue | Le pitch, le contexte, les festivals… (gras, italique, liens possibles) |
| **Image de couverture** *(obligatoire)* | L'affiche ou un photogramme |

3. **Ajouter l'image de couverture** : clique sur **« Choisir une image »** →
   **« Téléverser une nouvelle ressource »** → sélectionne le fichier sur ton ordinateur →
   clique sur l'image puis sur **« Choisir les éléments sélectionnés »**.
   Ton image sera compressée automatiquement : envoie-la en bonne qualité (JPG ou PNG,
   idéalement moins de 10 Mo).
4. **Ajouter des images dans la galerie** (photos de tournage, photogrammes…) :
   dans **Galerie d'images**, clique sur **« Ajouter image »**, choisis l'image, ajoute une légende
   si tu veux. Recommence pour chaque image. Tu peux les réordonner en les faisant glisser.
5. **Ajouter la vidéo** : dans **Vidéos**, clique sur **« Ajouter vidéo »** puis :
   - **Lien de la vidéo** : copie l'adresse de ta vidéo YouTube ou Vimeo depuis la barre d'adresse
     du navigateur (ex. `https://www.youtube.com/watch?v=Se1VeHF5sBQ`) et colle-la ;
   - **Format** : *Horizontal (16:9)* pour un film, *Vertical (9:16)* pour un format Reels/TikTok ;
   - **Durée** (facultatif) : au format `02:25` ;
   - **Miniature** (facultatif) : l'image affichée avant de lancer la vidéo. Si tu la laisses vide,
     c'est l'image de couverture qui est utilisée.
6. **Liens externes** (facultatif) : un festival, un article, la page d'un partenaire…
   Clique sur **« Ajouter lien »**, mets un texte (ex. *Sélection officielle*) et l'adresse.
7. **Mettre en avant sur l'accueil** : coche la case si tu veux que le projet apparaisse
   dans la « Sélection » de la page d'accueil.
8. **Ordre d'affichage** : 1 = en premier dans sa catégorie, 2 = ensuite, etc.

Ensuite, enregistre (voir la partie 6 : brouillon ou publication).

> ✅ Tu n'as rien d'autre à faire : le projet apparaît automatiquement dans la catégorie
> choisie, avec sa propre page, quelques minutes après la publication.

**Si un champ est entouré de rouge**, c'est qu'il manque une information obligatoire
(titre, catégorie ou image de couverture) ou qu'un lien n'est pas au bon format.

---

## 3. Ajouter une photo / une série d'images

Ton travail photo est sur ton site **Evastre Photographie** (le menu « Photographie »
y renvoie directement). Pour montrer des images sur ce portfolio (graphisme, affiches,
photos de plateau…), crée un **projet** :

1. **Projets** → **« + Projet »**.
2. Titre, catégorie (ex. *Motion design / Graphisme*), image de couverture.
3. Dans **Galerie d'images**, ajoute autant d'images que tu veux, avec une légende si besoin.
4. Enregistre puis publie.

Sur le site, les images s'affichent en mosaïque ; un clic les ouvre en grand
(flèches du clavier ou glissement du doigt sur téléphone pour passer à la suivante).

---

## 4. Modifier ta bio ou ta photo

1. À gauche : **Réglages du site** → **À propos**.
2. Modifie le texte dans **Bio**.
3. Pour la photo : **Photo d'Eva** → **« Choisir une image »** → **« Téléverser une nouvelle ressource »**.
   Dans **Description de la photo**, écris une courte phrase (ex. *Eva Masson sur un tournage*) :
   elle est lue par les personnes malvoyantes.
4. Enregistre puis publie.

Dans **Réglages du site**, tu peux aussi modifier :
- **Réseaux sociaux** : ajouter, modifier ou retirer un réseau (nom, adresse, icône) ;
- **Page « Pro / Perso »** : l'introduction et les liens vers tes autres sites ;
- **Accueil et informations générales** : l'image de fond de l'accueil, ton email de contact,
  et (dans « Textes de l'interface ») les libellés du menu et des boutons.

---

## 5. Les autres collections

- **Catégories** : pour créer une nouvelle catégorie (ex. *Documentaire*). Choisis la rubrique
  (*Projets scolaires* ou *Projets professionnels / personnels*), les rôles affichés sur la carte
  et une image de couverture. Elle apparaît automatiquement sur le site.
  ⚠️ Ne supprime pas une catégorie qui contient encore des projets.
- **Rôles** : pour ajouter un rôle qui n'existe pas encore (ex. *Cheffe opératrice*).
  Il sera ensuite proposé dans tous les projets.
- **Expérience professionnelle** : poste, structure, dates, description, lien.
  La page « Expérience » apparaît dans le menu dès que tu as ajouté la première.

---

## 6. Publier ou garder en brouillon

En haut de chaque formulaire :

| Bouton | Effet |
|---|---|
| **Enregistrer** | Sauvegarde en **brouillon**. Rien ne change sur le site. Tu peux revenir plus tard. |
| **Statut : Brouillon → En cours de révision** | Marque le brouillon comme « prêt à relire ». |
| **Statut → Prêt** | Le brouillon est prêt à être publié. |
| **Publier → Publier maintenant** | Mets le contenu **en ligne**. Le site se met à jour en 2 à 3 minutes. |

Pour retrouver tes brouillons : en haut de l'écran, menu **« Flux »** (le flux éditorial)
(trois colonnes : *Brouillons*, *En cours de révision*, *Prêts*).
Tu peux faire glisser une carte d'une colonne à l'autre.

**Modifier un contenu déjà en ligne** : ouvre-le, fais tes changements, **Enregistrer**
puis **Publier**. Tant que tu n'as pas publié, l'ancienne version reste visible sur le site.

**Supprimer** : ouvre le contenu → **« Supprimer l'entrée »** (en haut). Il disparaîtra du site
après la mise à jour.

---

## 7. En cas de problème

- **Mon projet n'apparaît pas** : vérifie qu'il est bien **publié** (et pas seulement enregistré),
  puis attends 2–3 minutes et recharge la page du site.
- **Je ne peux pas me connecter** : vérifie que tu as accepté l'invitation GitHub reçue par email.
- **L'image ne s'envoie pas** : elle est peut-être trop lourde ; exporte-la en JPG de moins de 10 Mo.
- Pour tout le reste : contacte la personne qui gère le site.
